## 6. Generic lessons

- Fix the independent findings before asking the blocking question. The one owner decision in round 1 held seven mechanical fixes hostage for 11 hours; the loop should say that a pause for a decision comes after everything that does not depend on it is committed and pushed.
- Tell a repeat reviewer what changed. Rounds 2 and 3 re-read 22 files and re-derived a thesis for a delta of one or two commits, at about 90 to 100 K output tokens each. A context-free reviewer can stay context-free about the author's reasoning while still being pointed at the range since the last round, and at the PR comments that record what was declined.
- A fix that changes an invariant needs a test of the invariant, not of the fix. The round-2 namespace fix passed its own single-deploy test and broke redeploy idempotency, which the PR body had already claimed as a rule; round 3 was needed only because the new test did not deploy twice.
- A declined design finding should be declined with a reason that would still hold next round. The `Generated::Gate { outfits }` shape was declined in round 2 and adopted in round 3 with nothing new learned, so the decline cost a second edit of code, docs and PR text.
- Reviewer orchestrators skip the skill's verification step when they judge their own reading sufficient; all three did, and each disclosed it. If the step is optional in practice, the skill should say when reading suffices; if it is not, the loop should check the Coverage line for it. The orchestrators also fed nested agents the conclusions they wanted back (round 3's API prompt), which the skill's fresh-context design is meant to prevent.
- Questions to the owner should name the layer of each term. Every design question in this session used PRD, ADR and code vocabulary interchangeably ("gate", "slot", "promote", `left_ungated`, "'before' blobs") and marked one option recommended; the owner took the recommendation five times out of five, which suggests the questions confirmed rather than decided.
- Read what the decision needs, not the whole file. `belle.json` (20 K chars), the live Mods listing (19 K) and three full library modules went into a context that then cost 102 M replayed tokens over the session; a grep for the sharing flags and a `find` for one folder would have served.
- Environment facts belong in the skill, not in each run. Three `python3` failures and three repeats of the scope-script fallback happened because SKILL.md hardcodes `python3` on a Windows host; the loop prompt already carries the gh path for the same reason, and the scope script should get the same treatment.
