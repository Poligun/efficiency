## 6. Generic lessons

- Re-review fix commits even when they look small: four real regressions in this session (PR #32 R2 findings 1, 2 and 6; PR #33 R3 finding 1) were introduced by the previous round's fixes, and the two rounds the author skipped as "small" (PR #33 R3, PR #36) were the same kind of change.
- An autonomous loop must create the review skill's knowledge directory once, or the "accumulate domain knowledge" feature never engages: five reviews proposed memory and discarded it, and later reviews re-read the same 3DMigoto source.
- Review skills that shell out must not hard-code `python3`; four of five deep reviews lost their first two or three calls to "Python was not found" on Windows, and one crashed on console encoding until `PYTHONUTF8=1` was set.
- Waiting on a reviewer should be filled with the next task's reading or with nothing at all in context; here the main thread idled for 42 of 123 active minutes while its 608k-token context was re-read on every turn, and the single 12-minute wait was long enough to have read #12's issue and the import code.
- Scripted multi-line edits through the shell are the wrong tool on this platform: seven failed attempts across three root causes (heredoc quoting, CRLF, backslash collapse) before the agent settled on writing the script to a file, and the memory note it saved names only one of the three causes.
- A lint with a hard line budget (`too_many_lines = 100`) on a function the branch keeps extending turns every review fix into a refactor; four extractions from `import_tree` in one session is a signal to either raise the budget for that function or split it once on purpose.
- Continuation prompts accumulate stale "waiting on" items unless each session re-verifies them against the repo; the owner's first question after an eight-hour gap was about an item an ADR had closed the day before.
- A GUI PR that the author cannot see needs either a screenshot step or a human look before the next task builds on it; PR #34's layout was reviewed twice for logic, never for what a user would understand from "No mods yet." and "Merge them", and was replaced in #16 before anyone looked.
