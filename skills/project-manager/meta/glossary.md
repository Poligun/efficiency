# Glossary

Shared vocabulary is in [pm-setup/meta/glossary.md](../../pm-setup/meta/glossary.md)
(seam file, operation vocabulary, standing rule, deliberate status, graduation).
Specific to this skill:

- **Audit** — the write-side mode: invariant checks producing a findings table
  and one confirmed fix batch.
- **Frontier** — the read-side mode: urgent / ready / in-flight / spec queue /
  backlog, ending in one suggested next action.
- **Orphaned work** — an open task whose parent epic is closed; flagged without
  a proposed fix because the remedy is a real decision.
- **Clean audit** — all invariants pass; reported in one line, not a report.
